## Short project introduction

Private Assistant AI is an experimental Windows desktop assistant that runs core reminders, voice processing, and activity-based suggestions locally. AI integrations are optional. The current interface and reminder grammar are primarily Traditional Chinese; project documentation is available in English and Traditional Chinese.
