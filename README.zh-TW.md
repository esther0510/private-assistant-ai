# Private Assistant AI

[English](README.md) | 繁體中文

**Windows 本機優先、可主動提供提醒的桌面助理。**
版本：`v0.1.0-alpha` · 實驗性版本

Private Assistant AI 協助管理提醒、整理電腦活動情境，並在可能反覆卡住時提供提示。語音指令、活動追蹤、輕量學習與規則式建議都在自己的電腦上執行；核心功能不需要 API key、付費 AI 訂閱或 AI 帳號。

目前介面與提醒語法以繁體中文為主。英文 README 是供國際讀者了解專案的文件，不代表介面或英文指令已全面支援。本文件整理現有功能與繁中操作說明；朋友測試包的 `START_HERE.txt` 保持原樣。

## 功能

### 配合日常活動的提醒

- 透過文字、語音或提醒清單新增、修改、刪除與復原（Undo）提醒。
- 支援單次、每日、每週、間隔、活動／休息週期提醒，以及沒有精確時間的「今日收件匣」。
- 情境提醒，例如下次開啟特定程式時提醒某件事。
- 提醒優先級（`critical`、`normal`、`low`）、稍後提醒、彈窗、Windows 通知、僅狀態列提示，以及離席後回來確認。
- 週期提醒會繼續排程；稍後提醒只延後這一次。
- 提醒服務隨程式啟動，與活動監督分開運作。關閉視窗會縮到系統匣；可選擇隨 Windows 開機安靜啟動。

### 本機語音喚醒與麥克風控制

- 自訂助理名字，使用 sherpa-onnx 本機關鍵字偵測（KWS）喚醒，再由 Whisper 在本機辨識指令。
- 共用自動／手動麥克風增益、麥克風測試、喚醒詞測試與裝置校準。
- 不需要錄音訓練。辨識效果受麥克風、噪音、距離、發音及喚醒詞詞典支援程度影響。

### 活動、情境與主動建議

- 偵測前景程式／視窗及閒置／離席狀態，將活動整理成工作階段，不會把每次標題變化都當成新工作。
- 動態狀態列顯示模式、程式、標題摘要、持續時間，以及 30 分鐘內到期的提醒；多螢幕位置處理包含 DPI 縮放輔助。
- 每日本機活動摘要，以及根據程式使用、提醒結果、回應時間和低風險呈現偏好的透明學習。
- 規則式「死循環」偵測，觀察反覆切換程式／視窗、重複標題或錯誤訊號及長時間活動。
- 「助理」頁籤整合目前情境、目標與休息習慣，提供保守的下一步建議。推測目標不會覆蓋手動目標；高風險變更保留為建議。
- 選用的外部通知反應學習 Beta 使用中介資料與程式切換時間；完整 Windows 通知接收仍有限。

### 啟動 App 與遊戲

透過本機安裝資訊與別名尋找程式和遊戲。目標不明確時需要選擇或確認；結果受安裝路徑、啟動器資訊、權限與啟動速度影響。送出遊戲 URI 只代表已要求啟動，不代表已驗證進入遊戲。

### 音遊診斷

原始碼版本提供本機 A/B 測試，用來比較遊戲設定。記錄譜面與共通條件，每次只改一項、交錯進行 A/B，手填結果或匯入每局 CSV 樣本，搭配 Windows 顯示資訊與 CPU 觀察。

FPS、frametime、準度及 timing 統計需要對應的外部資料或手填結果。不做 OCR、不讀遊戲記憶體、不注入按鍵，也不會自動量測輸入延遲。分析是啟發式證據，不是因果證明。完整流程與 CSV 格式請見 [音遊診斷說明](RHYTHM_DIAGNOSTIC.md)。

## 從原始碼安裝

目前開發環境使用 **Windows 64 位元與 Python 3.12**。下載並解壓原始碼，或在公開 repo 建立後複製專案，在專案資料夾開啟 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

需要語音喚醒時，另外安裝：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-voice.txt
```

啟動程式：

```powershell
.\.venv\Scripts\python.exe run.py
```

需要無命令視窗啟動時，可雙擊 `start_assistant.vbs`，它會優先使用專案的虛擬環境。若 Windows 的 Python 檔案關聯指向已安裝相依套件的環境，也可使用 `run_silent.pyw`。

原始碼 repo 不包含執行檔測試包。`START.bat` 需要另行提供的 `tools/uv/uv.exe`，該檔案不納入 Git。[START_HERE.txt](START_HERE.txt) 繼續提供獨立朋友測試包的繁中使用指南。

### 第一次模型下載

首次設定語音時會從 GitHub 下載 KWS 模型；首次辨識指令時還會從 Hugging Face 下載 Whisper 模型，因此需要網路。下載與初始化可能花數分鐘或更久，請預留數 GB 磁碟空間；語音準備期間仍可使用文字提醒。

KWS 模型位於 `%LOCALAPPDATA%\PrivateAssistantAI\models`，Whisper 使用自己的本機模型快取。模型不包含在此原始碼 repo，適用各自的上游授權條款。下載完成後，語音推論在本機執行。若下載失敗，請確認能連上 GitHub 與 Hugging Face，再使用語音元件的安裝／重試功能。

## 第一次使用

目前預設會開始監督。請閱讀首次提示，依需要暫停監督或開啟隱私模式；暫停監督不會停止提醒。

按 **Ctrl+Alt+A** 開啟指令輸入框，Enter 送出，Esc 取消，也可使用主視窗操作。

| 操作 | 範例 |
|---|---|
| 新增 | `10分鐘後提醒我喝水` |
| 指定時間 | `明天早上8點提醒我出門` |
| 週期 | `每天晚上10點半提醒我伸展` |
| 修改最近提醒 | `剛剛時間說錯了，改成下午一點` |
| 刪除 | `把喝水提醒刪掉` |
| 復原 | `復原剛剛的操作` |

務必核對畫面上的日期、時間與目標。有多筆相符提醒時需要選擇／確認。最近提醒的快捷操作約有 60 秒期限；提醒後續又有變更時可能無法復原。修改週期提醒會保留週期設定。正式提醒彈窗提供「完成」與「10 分鐘後」；「忽略」只用於助理主動產生的提示。

語音設定位於「設定 > 監督」：啟用語音助理、設定名字並選擇麥克風。等「待機中」出現，先喊名字，看到正在聽的提示後再說指令。請用平常距離測試麥克風、喚醒詞與校準。隱私模式或關閉語音會停止收音；縮到系統匣時仍可能持續待機。

### 設定對照

| 介面項目 | 用途 |
|---|---|
| `閒置時自動暫停監督`／`閒置門檻` | 離席時暫停監督／設定閒置判定時間 |
| `隱私模式` | 暫停行為監督、活動記錄、學習與死循環偵測 |
| `啟用學習` | 控制本機行為學習 |
| `外部通知反應學習 Beta` | 選用通知反應學習，預設關閉 |
| `死循環提醒` | 控制反覆卡住的提示 |
| `排除` | 以執行檔名稱或關鍵字排除敏感程式 |
| `AI Handoff` | 選擇手動送出提示詞的 AI 網站 |
| `AI Advisor` | 設定選用的 API 分析，預設關閉 |

要完全退出，請在系統匣圖示按右鍵，選「離開」。關閉主視窗不是退出；完全退出後提醒與語音都會停止。

## 隱私與本機資料

- 核心功能不會將螢幕、行為、提醒、學習或 SQLite 資料送出電腦。活動偵測使用本機程式／視窗情境，不是通用的螢幕視覺理解。
- 隱私模式暫停監督、活動記錄、學習與死循環偵測，必要的提醒排程仍保留。程式排除功能協助避免記錄敏感應用程式。
- 設定匯出／匯入只包含偏好與規則，不含活動歷史、提醒、通知內容、SQLite 紀錄與學習資料。另提供學習重設與完整個人資料重設。
- 本機優先不表示完全不連網：相依套件／模型下載、選用的更新資訊檢查、使用者操作的 AI Handoff，以及自願啟用的 Advisor API 都可能涉及外部服務。

Windows 資料庫位於原始碼資料夾外的 `%LOCALAPPDATA%\PrivateAssistantAI\assistant.sqlite3`。音遊診斷檔案存於旁邊的 `rhythm_diagnostics`。非 Windows 有 `~/.private_assistant_ai/assistant.sqlite3` 儲存備援路徑，但不表示支援其他平台的桌面功能。

若舊版 repo 內有 SQLite 檔案，而目的地尚無資料庫，啟動時會複製到使用者資料目錄，原檔保留不動。Git 忽略規則排除資料庫、日誌、截圖、學習資料、`.env`、金鑰、虛擬環境與建置產物。

請在程式內修改設定。`.env.example` 只是文件，程式不會自動讀取 `.env` 或其中的示意變數。選用 Advisor 憑證在設定介面輸入並存入本機資料庫，請保護資料庫，不要分享。

### 選用 AI 整合

**AI Handoff** 會整理近期本機事件與可能的重複模式。按「交給 AI 重新檢查」後，提示詞會複製到剪貼簿並開啟選定網站（ChatGPT、Grok、Claude、Gemini 或自訂網站）。請先檢查內容，再自行貼上與送出；它不會呼叫 API 或自動傳送提示詞。

**Advisor API** 是獨立、預設關閉的選用功能。啟用後可能將分析情境傳給你設定的 OpenAI 相容服務。提供服務商預設、模型選擇、連線測試與自訂端點。沒有可用 API 設定時會退回本機規則，並在介面／狀態顯示來源。ChatGPT 訂閱不等於 API 憑證或 API 額度。

### 更新檢查

更新檢查頻率低、只查版本資訊，也可關閉。公開 repo 尚未建立前，更新網址維持 placeholder：

```text
https://api.github.com/repos/<owner>/<repo>/releases/latest
```

日後發布前，維護者應更新 `personal_ai_assistant/updates.py` 與 `update_check_url` 設定。程式不會自動安裝更新。

## 已知限制與安全注意事項

- 這是 Windows 實驗性 Alpha，介面以繁中為主；自然語言解析支援常見中文指令與簡單時間格式，不是完整日曆語法。
- 語音可能辨識錯名字、時間或指令；電視／遊戲聲音也可能誤喚醒。罕見名字、方言、噪音與硬體影響效果，不保證辨識延遲。CPU 即可使用，不要求 NVIDIA 顯示卡。
- 睡眠、關機或完全退出程式時無法準時提醒；離席／鎖定狀態可能延至回來再確認。重要事項請保留其他提醒方式。
- 死循環偵測與 Advisor 建議可能判斷錯誤，規則與情境訊號不能完整理解你的意圖。
- 全域快捷鍵可能衝突；多螢幕及混合 DPI 仍需實機驗證。獨佔全螢幕遊戲可能阻擋覆蓋視窗，通知／狀態提示效果依環境而異。
- 外部通知反應學習是自願啟用的 Beta；本版完整 Windows 通知接收仍有限或不可用。
- 測試包可能沒有數位簽章。遇到 Windows 或防毒警告時，先確認來源與檔案完整性，不要關閉整套防毒。
- 程式啟動與音遊診斷另有上述限制。更多待驗證項目與發布前待辦請見 [已知問題](KNOWN_ISSUES.md)。

## 開發與貢獻

程式位於 `personal_ai_assistant/`。既有平面模組與 `core/`、`ui/`、`assistant/`、`integrations/` 並存，以便逐步整理而保留 Alpha 行為。

文件變更可使用以下輕量檢查：

```powershell
git diff --check
python scripts/privacy_audit.py --git-index
```

隱私稽核掃描 Git 暫存區，包含全部已追蹤檔案；請先暫存預期變更。模式掃描不能保證找出所有秘密或私人資訊。程式行為變更可能需要 [貢獻指南](CONTRIBUTING.md) 與 [發布檢查清單](RELEASE_CHECKLIST.md) 的進一步檢查。

提交 issue、日誌、截圖或重現資料時，請移除私人提醒、視窗標題、活動歷史、資料庫、憑證與 API key。安全問題請見 [安全說明](SECURITY.md)。

後續方向包括首次使用引導、更完善的程式／視窗排除、本機活動檢視與刪除、更多提醒語法與語系、模型轉接、Windows 安裝包，以及隱私／資料遷移驗證。
