Private Assistant AI 朋友測試版｜2026-09-14

一、開始使用
1. 在 ZIP 上按右鍵，選「解壓縮全部」。請解壓到你有寫入權限的資料夾，例如桌面。
2. 打開解壓後的 PrivateAssistantAI 資料夾，雙擊 PrivateAssistantAI.exe。
3. 請保留旁邊的 _internal 資料夾，不要只把 exe 拿出來，也不要直接在 ZIP 裡啟動。
4. 不需要安裝 Python。第一次開啟可能稍慢，請等主視窗出現，閱讀初始提示後按確定。
5. 預設會開始監督目前使用的程式。想暫停，可在主畫面暫停監督；需要私人時間時可使用隱私模式。

二、先用文字試試
按 Ctrl+Alt+A 叫出指令輸入框，輸入後按 Enter，取消則按 Esc。
也可以从主視窗操作提醒。
試試：「10分鐘後提醒我喝水」。請確認画面上的日期與時間符合你的意思。
核心提醒不需要 API key，也不需要登入任何 AI 帳號。

三、開啟語音與麥克風
到「設定 > 監督」開啟語音助理，設定名字，例如「賈維斯」，再選擇自己的麥克風。
語音套件已經內建。第一次啟用語音需要網路下載喚醒模型；第一次辨識指令還會下載 Whisper small 模型。
模型不放在 ZIP 裡。下載及初始化可能需要數分鐘或更久，依網速與電腦速度而定，請預留數 GB 磁碟空間。
等狀態顯示「待機中」再喊名字；不需要錄音訓練。
先喊「賈維斯」，看到正在聽的提示後說「十分鐘後提醒我喝水」。熟悉後也可連著說。
「測試麥克風」可檢查訊號；「測試喚醒詞」可試名字。請用平常距離與音量。
共用麥克風增益與喚醒靈敏度預設自動；可用校準功能適應自己的設備。
隱私模式或關閉語音會停止收音；關閉視窗縮到系統匣時仍可能持續待機。

四、新增、修改、刪除與復原提醒
新增：「10分鐘後提醒我喝水」「明天早上8點提醒我出門」。
週期：「每天晚上10點半提醒我吃藥」。
午夜：「十二點半提醒我睡覺」會按凌晨 00:30 理解；中午請明說「中午十二點」。
時間不明確時可能會問你，請核對日期與時間。
剛建立後說：「剛剛時間說錯了，改成一點」。為免誤會，建議明說「凌晨一點」或「下午一點」。
刪除剛剛建立的：「刪掉剛剛那個提醒」或「取消剛剛那個」。最近提醒的快捷操作約有 60 秒期限。
指定刪除：「把喝水提醒刪掉」。有多筆相同名字時請選正確的一筆，並依提示確認。
復原最近修改或刪除：「復原剛剛的操作」。提醒後續又有變更時，可能無法復原。
也可以在提醒清單使用修改／刪除入口。修改週期提醒會保留週期設定。
提醒到時可選完成或 10 分鐘後；電腦睡眠、關機或程式完全退出時無法準時通知。

五、常見問題
• 無法喚醒：先確認已啟用語音、名字已設定、狀態是待機中，而且沒有開隱私模式。
  檢查是不是選錯麥克風或硬體靜音，再用測試麥克風／校準功能。太短、特殊發音的名字可能不好辨識。
• Windows 麥克風權限：到 Windows「設定 > 隱私權與安全性 > 麥克風」
  （Windows 10 為「隱私權 > 麥克風」），開啟麥克風存取及允許桌面應用程式存取。
• 第一次模型下載失敗：確認能連上 GitHub 與 Hugging Face，網路恢復後按語音元件的安裝／重試。
  模型初始化期間請耐心等候；文字提醒仍可使用。下載完成後模型會留在自己的電腦，後續通常不用重抓。
• 缺少語音元件或 DLL：重新解壓整份 ZIP，確認 _internal 沒有被刪除或隔離；exe 版不用自己裝套件。
• 被防毒或 SmartScreen 攔下：本測試版沒有數位簽章，可能出現警告。
  先向提供檔案的人確認來源與檔案是否完整，再依 Windows 提示處理；不要關閉整套防毒。
• 沒有跳出提醒：確認程式仍在執行、提醒未完成、時間正確；離席時可能會等你回來再確認。
• 語音辨識慢或英文名字不準：這版主要使用本機模型，速度與準確度依硬體、噪音和說法而不同。
  可先用文字輸入；CPU 即可使用，不要求 NVIDIA 顯示卡。

六、完整退出
按主視窗右上角 X 只是縮到系統匣，不是退出。
在 Windows 右下角找圖示（可能藏在向上的小箭頭裡），按右鍵，選「離開」。
退出後語音與提醒會停止。不要只刪除資料夾來關閉程式。

七、自己的資料與限制
這份包不含提供者的 API key、帳號、聊天、提醒、別名、麥克風校準或個人設定。
第一次啟動會在自己的 Windows 使用者資料夾建立資料；若同一帳號曾用過此程式，會沿用既有資料。
本機資料通常位於 %LOCALAPPDATA%\PrivateAssistantAI；Whisper 使用本機模型快取。
AI API 分析預設關閉；想用時需自己設定，不需要借用提供者的 key。
這是 Windows 64 位元 Alpha 測試版。不同麥克風、噪音、全螢幕遊戲與安全軟體仍可能影響效果。
重要事情請保留其他提醒方式。回報問題時描述操作步驟與畫面訊息即可，不要傳送自己的 API key 或整份私人資料。
