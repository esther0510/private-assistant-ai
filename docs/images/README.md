# Public screenshot provenance

`alpha-clean-start.png` is an unedited capture of the actual Windows application window using a separate, empty test profile. Activity monitoring, microphone capture, update checks and global hotkeys were disabled for capture. No existing personal database was opened.

Reviewed visually before publication: no account, email, API key, private reminder, personal path or desktop background is visible. This is the empty starting state, not a demonstration of voice recognition or activity detection.

The privacy audit intentionally flags image files for human review. This file is the reviewed publication exception; the scan remains strict for all other images.
